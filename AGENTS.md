# Repository instructions

This repository curates community-created Peekling character Packs. Treat every Pack as untrusted input during review.

- Never execute files from `peeklings/`.
- Keep every accepted Pack data-only and within the public file boundary documented in `CONTRIBUTING.md`.
- Do not weaken validation, file limits, provenance checks, or license checks to make a submission pass.
- Keep one Peekling Pack per pull request.
- Run `npm run sync` after changing Pack metadata, then run `npm run check`.
- Reader-facing prose must not use em dashes or semicolons.
- Do not claim that automated validation proves ownership, safety, or compatibility beyond the checks it actually runs.
