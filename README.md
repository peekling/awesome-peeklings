# Awesome Peeklings

A curated home for community-created Peekling character Packs.

Every Peekling in this repository was submitted by its creator or an authorized collaborator. Each accepted Pack is data-only, carries its own license and rights record, and passes the same public Pack validator used by the [Peekling engine](https://github.com/peekling/peekling-engine).

This is the community collection. Official first-party characters live in [`peekling/peekling-characters`](https://github.com/peekling/peekling-characters).

Visit [peekling.com](https://peekling.com) to meet Peekling, then bring your own character.

## What belongs here

This repository keeps complete community Packs, not a list of links. Every Pack includes its runtime manifest, referenced PNG atlases, thumbnail, introduction, license, and creator rights record.

Community Packs are:

- created and maintained by community contributors
- reviewed for character fit, declared rights, and a data-only file boundary
- validated for manifest structure, atlas hashes, image geometry, size limits, and required movement states
- distributed under the license chosen by their creator

Automated checks cannot prove ownership or remove every risk. Inclusion means the submission met this repository's current checks and curation guidelines. It does not make the Pack official or first-party.

## Add your Peekling

Start with the [contribution guide](CONTRIBUTING.md). It covers the Pack layout, accepted licenses, `RIGHTS.json`, local validation, and the pull request process.

One pull request should contain one Peekling. The gallery and catalog are generated from accepted Pack metadata, so your character appears here when the pull request is merged.

If you have an early idea, open a [Peekling proposal](https://github.com/peekling/awesome-peeklings/issues/new?template=peekling-proposal.yml). Designers, illustrators, animators, and developers are all welcome.

## Use a community Pack

Clone or download the repository, then point a compatible Peekling runtime at a Pack's `character.json`. For hosted use, publish the Pack files through your own static host or use a commit-pinned GitHub CDN URL. Do not depend on the moving `main` branch in production.

Review the Pack's `LICENSE`, `RIGHTS.json`, and README before redistributing it. Community creators support their own work.

## Community guidelines

The [`COMMUNITY_GUIDELINES.md`](COMMUNITY_GUIDELINES.md) file is the community standard for participation, artwork rights, review, and curation in this repository. The short version is simple: bring work you can share, disclose how it was made, keep Packs data-only, and treat people with care.
